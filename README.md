# 1-listit

## Descripción

Este ejercicio contiene un script llamado `1-listit` que debe ejecutarse correctamente sin mostrar ninguna salida en pantalla.

## Ejecución

Para comprobar que el archivo existe:

```bash
ls
```

Salida esperada:

```text
1-listit
```

Luego se ejecuta:

```bash
./1-listit
```

El programa debe finalizar correctamente y no mostrar ninguna salida.

## Salida esperada

```text
$ ls
1-listit

$ ./1-listit
```

El código de retorno esperado es `0` y no debe haber contenido en `stdout` ni en `stderr`.
